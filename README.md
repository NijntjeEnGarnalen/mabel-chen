# Mabel Chen — portfolio (mono)

Static site, no build step. A monospace, index-style edition of the work on mabelchen.net (the MJ_Studio repo, which this repo does not touch).

- `index.html` — all projects as a vertical image stack; fixed numbered list on the left
- `<project>.html` — text + credits on top, every image/video below
- `information.html` — bio, education, experience, languages
- `mori-research.html`, `mellow-research.html` — research decks
- `media/` — web-sized copies of the MJ_Studio images (max 2000px, JPEG)
